# YeonWoo
Stitch v5.4 project files
연우 (YeonWoo)
"충동구매는 이제 그만, 100점짜리 의사결정을."

연우는 사용자의 소비 습관을 분석하고, 무신사/29CM 등 패션 쇼핑몰의 URL을 통해 9대 가중치 지표로 구매 타당성을 분석해 주는 의사결정 보좌관 프로젝트입니다.

Zero-Cred 원칙: 계정 정보나 로그인 토큰을 저장하지 않는 로컬 우선 보안 설계.
의사결정 엔진: 가용 예산, 코디 호환성, 중복 소장 여부 등 9개 지표를 통한 합리적 소비 제안.
iOS/PWA 지원: 앱처럼 홈 화면에 추가하여 빠르게 사용 가능.
